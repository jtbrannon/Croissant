# Croissant
Croissant is a web application developed in Angular and Python to automatically display various modular tools and webpages in a drag-and-drop format to present a variety of online sources and utilities in one convenient web interface. Croissant utilizes Angular for its frontend with a combination of TypeScript, HTML, and CSS and Python on its backend to manage data and send API requests. The website features a homepage that can store smaller HTML elements into an overarching lists as well as a login page developed in TypeScript. 

This project was developed in Fall 2021 as part of a UNCG Computer Science Course, CSC-340: Software Engineering.
