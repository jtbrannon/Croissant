# Croissant
Croissant is a web application developed in Angular and Python to automatically display various modular tools and webpages to present a variety of web tools in one convenient web interface. Croissant utilizes Angular for its frontend with a combination of TypeScript, HTML, and CSS and Python on its backend to manage data and send API requests. The website features a homepage that can store smaller HTML elements into an overarching lists as well as a login page developed in TypeScript. 

This project was developed in Spring 2022 as part of a UNCG Computer Science Course, CSC-340: Software Engineering in Spring 2022.
